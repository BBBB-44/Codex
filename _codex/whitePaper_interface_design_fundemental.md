# Interface design fundemental

- User should alway be able to naviguate from anywhere toward any valid destination. (no dead end).

- Irreversible action should always be confirmed with user first.

- A source of information should only be displayed once. (One source of truth, as to not confuse user).

- Only needed option should be displayed, every other options should be hidden or in a submenu. (less is more).

- Color theme, animation and other customisation option, should help the user understand your interface. (Make it more intuitive).

- Too many options lead to wasted time processing such information for human.

- Every action needed by the user should be done in the least step possible.

- Possible action should be near their context.

- Icon help.
